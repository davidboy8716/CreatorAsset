# CreatorHub AI 测试版

本地优先的 AI 素材管理工具 —— 公开测试版发布仓库（免激活，功能完整）。

## 下载
前往 [Releases](https://github.com/davidboy8716/CreatorAsset/releases) 下载最新测试包：

1. 下载 \creatorhub-*.zip\ 并解压；
2. 运行 \pp\CreatorHub.App.exe\；
3. SmartScreen 提示时选择「更多信息 → 仍要运行」（未签名测试包）。

## 环境要求
- Windows 10/11 x64
- .NET 8 桌面运行时（首次启动按提示安装即可）

## 功能
OCR / 语音转写 / 中文语义搜索 / 以图搜图 / 素材管理 / 应用内预览 等全部 AI 能力。
